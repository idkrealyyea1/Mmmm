البنية التقنية للمشروع

The Technology Behind It
🔌

واجهة برمجية API آمنة

خادم Express يقدّم +40 عملية: توفر الأيام، الأسعار، جميع الحجوزات، الإحصائيات، الفواتير والمزيد.

🗄️

قاعدة بيانات سحابية (Supabase)

جداول حجوزات الخدمات الخمس + المستخدمين + الأسعار + الأيام المغلقة + التقييمات + الإشعارات.

🔐

أمان وتسجيل دخول

كلمات مرور مشفّرة (bcrypt) ومدخلات JWT مع صلاحيات لكل دور: مدير / مصوّر / عميل.

🔔

إشعارات ويب فورية

تقنية Web Push (VAPID) — إشعار للعميل عند تأكيد الحجز، وإشعار للإدارة عند وصول طلب جديد.

📱

تطبيق ويب (PWA)

عامل خدمة (Service Worker) يسمح بالتثبيت على الجوال وتلقي الإشعارات في الخلفية.

📞

توحيد أرقام الهواتف

نظام يوحّد صيغ الأرقام تلقائياً لتطابق الحجوزات وتتبعها بدقة.

C المكدس التقني (Tech Stack)
الطبقةالتقنية
